# StudyHub

Build a small **study management app**. Complete the following steps in order, extending the same project each time.

1. **Practice game:** Create a number-guessing game (1–100) with high/low hints, an attempt counter, and a final point score.
2. **Gradebook:** Store student profiles and their practice scores. Support adding scores and calculating averages, minimums, maximums, and letter grades.
3. **Assignment tracker:** Let each student add, complete, delete, and filter assignments by completion status.
4. **Class analytics:** Support multiple students. Rank them by average score, identify students below a chosen threshold, and calculate assignment completion rates.
5. **Immutable updates:** Refactor assignment and student updates to return new arrays/objects rather than modifying existing ones.
6. **Rewards store:** Add a catalog of rewards purchasable with practice points. Support a cart, quantities, totals, and insufficient-points checks.
7. **Admin page:** Add an admin page where you can add or remove items from the rewards store.
